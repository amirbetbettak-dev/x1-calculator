# x1 — ماشین‌حساب مدرن آبی یخی (Frosty Blue Calculator)

برنامه ماشین‌حساب مدرن **x1** با طراحی شیشه‌ای و یخی (Glassmorphism & Ice Theme)، انیمیشن‌های روان پاشش ذرات یخ هنگام لمس کلیدها و افکت بارش برف در پس‌زمینه.

---

## 🚀 راهنمای اجرا در ترمینال سیستم (گام به گام)

### پیش‌نیازها:
- نصب بودن **Node.js** (نسخه ۱۸ به بالا) از [nodejs.org](https://nodejs.org/)
- نصب بودن **Git** از [git-scm.com](https://git-scm.com/)

### ۱. کلون کردن مخزن:
```bash
git clone https://github.com/amirbetbettak-dev/x1-calculator.git
cd x1-calculator
```

### ۲. نصب بسته‌ها:
```bash
npm install
```

### ۳. اجرای برنامه در مرورگر (حالت توسعه):
```bash
npm run dev
```
پس از اجرای دستور، آدرس نمایش داده شده در ترمینال (معمولاً `http://localhost:5173`) را در مرورگر باز کنید.

### ۴. دریافت فایل نهایی نصبی/ساخت (Production Build):
```bash
npm run build
```
پوشه `dist` ساخته خواهد شد که شامل خروجی نهایی استاتیک، سریع و سبک برنامه است.

---

## ✨ ویژگی‌ها:
- طراحی زیبای Ice Blue با طیف‌های رنگی مدرن و بلور شیشه‌ای
- انیمیشن پاشیدن تکه‌های یخ هنگام کلیک روی دکمه‌ها
- بارش ملایم و تصادفی دانه‌های برف
- پشتیبانی کامل از کیبورد کامپیوتر (اعداد، عملگرها، Backspace و Enter)
- ساخته شده با React 19، Tailwind CSS v4 و Vite
